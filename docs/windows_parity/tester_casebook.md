# Windows casebook for the supplied tester report

`C:/Users/Satoshi/Documents/VOOL Windows/05_Baseline_Evidence/message.txt` is an external report. Its statements are hypotheses until reproduced against this checkout or an installed artifact. No step below authorizes changing Phantom signing/authentication or handling private keys. The Mac GitHub repository is not an edit target.

| Case | Current Windows-source finding | Required reproduction and closure gate |
| --- | --- | --- |
| R01 — mesh listener, privacy labels, memory exhaustion, port takeover | The API bootstrap defaults the Windows mesh daemon off; the bundle additionally forces `VOOL_DISABLE_MESH_DAEMON=1`. The earlier Windows installer port-kill code was removed. | On a clean installed VM, inspect listeners and try unauthenticated mesh requests, overlarge payloads, and occupied-port launch. No default mesh listener, disclosure, OOM, or unrelated process termination. An opt-in mesh is a separate security review. |
| R02 — request fragments sent to peers | Unverified for the Windows artifact. | Send unique canary prompts with outbound packet/DNS capture; correlate every destination and payload to a declared, consented capability. No peer request egress by default. |
| R03 — search leakage | Unverified for the Windows artifact. | Ask local-only questions containing canaries and observe search endpoints and payloads. No automatic external search before clear user authorization; retain optional search utility after explicit enablement. |
| R04 — public Hive presence, idle posting, strangers' work | Public Hive requires an enable flag and seed URLs; bundle forces the flag off. Several stored preference defaults are still true and need UX/consent reconciliation. | Capture traffic through first run and sustained idle; inspect persisted settings and capability report. No presence/post/task/search egress by default; opt-in must be explicit and reversible. |
| R05 — Hands-off commands bypass approval | `core/execution_gate.py` uses a heuristic destructive-command check in Hands-off. `sandbox/job_runner.py` refuses Windows executable jobs without OS isolation. The Windows `core/plugin_executor.py` `heuristic_only` escape has now been closed. | Adversarial scratch-workspace corpus for deletion, interpreter, plugin/MCP, build-script, child-process, and egress variants. No protected command can execute until the native broker and native approval contract pass escape tests. |
| R06 — local `HIGH`/approval forgery | `core/request_trust.py` explicitly equates any loopback process with owner-local. The new exact browser-origin guard does not authenticate no-Origin local clients. | Separate same-user and other-user local clients attempt privilege, settings, approval, spend, and shutdown changes. Deny unless a trusted native host/broker binds the exact operator gesture and typed effect. **Open release no-go.** |
| R07 — browser without sandbox | Windows native host uses pywebview/WebView2; no installed artifact or WebView2 process-policy proof yet. | Inspect signed installed processes, command line, profile ACL, navigation/bridge limits, and hostile remote content. No `--no-sandbox`, untrusted origin bridge, shared browser profile, or browser fallback. |
| R08 — OpenClaw config written on boot | Confirmed source call. The Windows bundle now skips registration unless `VOOL_ENABLE_OPENCLAW_INTEGRATION=1`; source tests cover both branches. | Clean VM with no OpenClaw: install, start, rename, repair, uninstall; `.openclaw` must stay absent. Explicit integration needs consent, scoped write, and rollback. |
| R09 — signed-update claim | Publisher feed/key and installed Windows updater proof remain absent. | Tamper, replay, downgrade, feed outage, staging, rollback, and signature-chain tests on the signed artifact. UI must say updates are unavailable until configured. **Open release no-go.** |
| R10 — uninstall deletes models | The Inno source currently preserves per-user VOOL data/models; installed behavior is untested. | Install with VOOL-owned and unrelated Ollama models, uninstall and repair, compare hashes and ownership. No third-party model or user-data deletion. |
| R11 — wallet mainnet and fee disclosure | Tester claim is not adjudicated here; wallet/auth code is locked for this port. | Owner-led, read-only review of actual installed UI and network/fee disclosures, then a separately authorized change if needed. No private-key handling or incidental signing change. **Open release gate.** |
| R12 — login/startup persistence | Mac report is not evidence of Windows persistence. | Snapshot HKCU Run keys, Startup folder, Scheduled Tasks, services, and protocol registrations before/after install, stop, repair, and uninstall. Only disclosed, owned entries may remain. |

Additional Windows attacks must cover junction/reparse/UNC/long-path escapes, process and port impersonation, local API CSRF/replay, WebView2 profile and navigation, DPAPI/credential theft boundaries, installer/update substitution, reboot recovery, and rollback. Each case needs the same signed artifact hash as the proposed release; source tests alone are not closure.
